# Security Policy

## Supported versions

Security fixes are made for the latest published version of each of the three packages: `TokenGuard.Core`, `TokenGuard.Extensions.OpenAI` and `TokenGuard.Extensions.Anthropic`. Earlier versions do not receive fixes; upgrade to the latest version to get one.

## Reporting a vulnerability

Report a vulnerability through GitHub private vulnerability reporting. Open the repository's Security tab and choose "Report a vulnerability", or go directly to <https://github.com/svetstoykov/TokenGuard/security/advisories/new>.

Do not open a public issue, pull request or discussion for a vulnerability. Those are visible to everyone before a fix exists.

In the report, include the package and version, a description of the problem and its impact, and the smallest steps or code that reproduce it. Remove API keys and private content before sending.
